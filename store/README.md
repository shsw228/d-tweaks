# Store assets

Screenshots for the listing. The store accepts 1280x800 or 640x400 only, so a 2x capture
must be resized (`sips -z 800 1280 in.png --out out.png`).

- `01-player.png` … the float player: the URL field for the video, the chapter strip and
  the comment histogram under the seek bar, the comment list and the debug view. The
  picture of the video is black because a screen capture blanks protected video (see
  `player_modal`), not because of a defect.
